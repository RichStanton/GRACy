## Decisions

- **Delivery = one issue → one PR**, Claude builds and verifies, user owns merges. Code changes go
  through branches/PRs; only housekeeping (this consolidation, docs) goes straight to `master`.
- **GitHub Issues is the tracker** (not files in git); `operations/delivery/backlog.md` is the
  git-tracked mirror so progress is visible in the repo too.
- **Verification is two-tier.** Logic bugs (BUG-2/3/4/5) get isolated tests now; BUG-1 gets a headless
  PyQt5 test; true end-to-end scientific correctness waits on the toolchain + a golden dataset (#11).
