# Session 2 — fresh-clone install regression (PR #29)

User reported that on a fresh clone `install.sh` **failed to install the toolchain**, with logs
attached under `feedback/`. This session diagnosed, fixed, verified, and merged it.

## What was done

- **Diagnosed from the logs.** Two stacked failures, both introduced when #7/#8 switched to
  downloading `Miniconda3-latest`: (1) modern conda's **Terms-of-Service gate** on the Anaconda
  default channels (`CondaToSNonInteractiveError`) aborted every install in run 1; (2) `-latest`
  ships **Python 3.14**, pinned into the base env, so the version-pinned bio tools (need Py3.6/3.7)
  were **unsolvable** — 11 still failed in run 2 after the user set `CONDA_PLUGINS_AUTO_ACCEPT_TOS`.
  Confirmed root cause against the local known-good `src/conda` (py37 / conda 23.1.0), which has all
  the failing packages installed.
- **Fixed** by pinning the Miniconda3 download to `Miniconda3-py37_23.1.0-1-Linux-x86_64.sh` — one
  line, **no tool-version changes**. conda 23.1.0 predates the ToS gate and gives the Py3.7 base the
  tools were pinned against. Added a `WHY` comment + regression test
  (`tests/test_install_miniconda_pin.py`, fails if repointed at `-latest`) + `.gitignore` entry.
- **Verified the non-obvious way.** Skipped the misleading one-package check; ran the **full 25-tool
  sequential reinstall** from the pinned installer in `install.sh`'s real order/channels/pins into one
  throwaway env: **30/30 installed, 0 failures, 0 ToS gates**. Every `-c anaconda` install checked
  for the ToS gate directly (the run-1 killer); all clear. Matches the known-good baseline.
- **Added a project `tester` subagent** (`.claude/agents/tester.md`) — an all-round test engineer
  with an ownership + earned-trust mindset (treat claims as hypotheses; prove real behaviour over
  proxies; red→green for regression tests, reproduce-the-baseline otherwise; writes only under
  `tests/`). Iterated the prompt with the user (simplified for harness freedom, then merged a
  structure-vs-substance rewrite).
- **Recorded** an executive summary (`../delivery/2026-07-23-install-toolchain-fix.md`) and
  **ADR-0001** (pin the Miniconda3 installer to py37).
- **Merged PR #29** (squash, `--delete-branch`) on the user's explicit instruction; `master` now
  @ the #29 squash commit, **16 tests green**. Pruned the stale remote-tracking ref.
