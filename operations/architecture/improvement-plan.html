The combined view — impact × risk

Numbers are the ranked items below. Top-left is the sweet spot: big gain, low chance of breaking working science.

1

End-to-end smoke test on testDataset/ + CI

Impact High Risk Low impact review

Problem. No test anywhere; every risky change below is a blind edit. Do. testDataset/ ships 4 input FASTQs but no golden output — so step one is a smoke + sanity run (pipeline completes without error; genome non-empty and plausible), then pin a known-good result as a golden file for true regression power. Wire to CI. This is the safety net that makes 2–10 safe — do it first.

2

Command-runner module run(tool, *args)

Impact High Risk Low–Med both lenses

Problem. ~605 inline os.system(installationDirectory+"src/conda/bin/…") sites, path hand-typed, return codes discarded — a failed alignment continues silently and produces wrong science. Do. One deep module that resolves the tool path, runs it, checks the return code, and logs. Merges the impact review's "return-code wrapper" with the depth review's #1 deepening.

  • • leverage: 605 sites, one interface
  • • locality: silent-failure fixed once
  • • the interface becomes the test surface
3

Delete the dead non-Qt twins (+ .bak, ._ copies)

Impact Med Risk Low both lenses

Problem. Every live *Qt.py has a stale non-Qt twin (assembly.py, genotyping.py, snpCalling.py, annotation.py) — verified unreferenced in code and in install.sh — plus .bak and ._ copies. They defeat locality: a fix to the runner/alignment/config would have to be applied to dead copies too. Do. Delete them (keep src/.GRACy_main.py — install.sh builds the launcher from it). Precondition for 2, 5, 8 having one home.

4

Repo hygiene — un-track Miniconda installers, junk; fix .gitignore

Impact Med Risk Low impact review

Problem. .git is 332 MB — Miniconda installers (~117 MB), old webin-cli jars, and .DS_Store/._* AppleDouble files all tracked; .gitignore only excludes conda dirs. Do. Delete from working tree, extend .gitignore, download Miniconda at install. History purge to reclaim the 332 MB is a separate, higher-risk force-push — optional.

5

Alignment module align(reads, ref) → bam

Impact Med–High Risk Med depth review

Problem. The bowtie2/bwa build→align→view→sort→index chain is one behaviour re-typed at ~28 sites (97 samtools calls across 11 files); bowtiePE/bwaPE proved the small interface but never left the assembly module. Do. Promote to a shared module returning a sorted BAM. Sits on top of the runner (2).

  • • locality: alignment tuning in one place
  • • two adapters behind one seam: bowtie2 + bwa
6

Extract a headless pipeline module — move the GUI↔pipeline seam

Impact High Risk Med–High both lenses

Problem. Pipeline logic is a side-effect blob inside Ui_Form.performAssembly — no return values, state via os.chdir + files + the log widget. The test surface is the Qt widget. Do. Extract assemble(config, log=cb) → result; the GUI becomes a thin adapter. Enables HPC batch + CI runs. Largest item — attempt only after 1 (tests) and 2 (runner) exist.

7

Fix the committed GRACy.py artifact + hardcoded HPC path

Impact Med Risk Low–Med impact review

Problem. GRACy.py is a build artifact install.sh regenerates, yet the committed copy bakes in /home3/scc20x/… (lines 1–2) — a fresh clone is broken until install runs. Do. Gitignore it and generate at install, or template the path cleanly. Cheap and blocks nothing — a quick-win you can pull into the first block.

8

Config module — keyed, validated parsing

Impact Med Risk Med both lenses

Problem. assembly.conf is parsed positionally (readline().split("\t")[1]), schema-less and copy-pasted; a reordered or missing line silently shifts every field. Do. One config module parsing to a typed, validated object shared across modules; malformed configs fail loudly at load. Pairs with assemble(config) from 6.

9

os.system → subprocess.run([...], shell=False) — injection safety

Impact Low–Med* Risk High impact review

Problem. User-supplied args (project name, file paths) concatenated raw into shell strings — injectable. *Low consequence in a trusted lab; high if ever distributed. Do. Convert to argument lists behind the runner (2). ~428 of the 858 calls (about half) rely on shell features (pipes, redirects, &, cd, globs), so a blind shell=False conversion breaks them — incremental only, behind the test net. Once the runner exists, this becomes changing one module's implementation.

10

Collapse the Python 2 env (RAGOUT now runs on Py3)

Impact Med Risk Med impact review

Problem. install.sh builds a second EOL Python 2 conda env solely for RAGOUT scaffolding. Do. Move RAGOUT to Py3, single env, simpler install. Scaffolding is science-sensitive — verify output is unchanged under the smoke test (1) before removing the old env.

Also — easy polish (below the top 10)

11 · Polish Impact Low · Risk Low–Med — fix the 201 >null redirects (a literal file named null, not /dev/null), the four log/UI typos, and write a real README for this fork. Mechanical; verify under the smoke test.
