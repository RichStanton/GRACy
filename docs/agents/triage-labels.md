# Triage Labels

The skills speak in terms of five canonical triage roles. These map 1:1 to label strings on
`RichStanton/GRACy` (no renaming needed — created directly with these names).

| Canonical role   | Label in this repo | Meaning                                  |
| ---------------- | ------------------- | ----------------------------------------- |
| `needs-triage`    | `needs-triage`       | Maintainer needs to evaluate this issue   |
| `needs-info`      | `needs-info`         | Waiting on reporter for more information  |
| `ready-for-agent` | `ready-for-agent`    | Fully specified, ready for an AFK agent   |
| `ready-for-human` | `ready-for-human`    | Requires human implementation             |
| `wontfix`         | `wontfix`            | Will not be actioned (pre-existing label) |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the label string as-is.
